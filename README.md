# SIGR - Sistema Integral de Gestión de Restaurante

## Descripción

Aplicación web para la gestión operativa de un restaurante. Permite visualizar
el menú digital, registrar pedidos en línea con cálculo automático del total y
gestionar reservas por fecha y hora con confirmación automática.

## Estructura del proyecto

```
sigr/
 |-- index.html          Página principal (menú, pedidos, reservas)
 |-- css/
 |    |-- style.css      Estilos de la interfaz
 |-- js/
 |    |-- script.js      Lógica de pedidos y reservas
 |-- README.md           Documentación del proyecto
 |-- CHANGELOG.md        Historial de cambios hasta la línea base
 |-- LICENSE.txt         Licencia MIT
```

## Tecnologías utilizadas

- HTML5: estructura de la página web.
- CSS3: diseño y estilos.
- JavaScript: funciones e interactividad.
- Git y GitHub: control de versiones y repositorio oficial.

## Funcionalidades

- Menú digital de platos con precios.
- Agregar productos al carrito de pedidos.
- Cálculo automático del total del pedido.
- Vaciar el carrito.
- Reservas por fecha y hora con confirmación automática.

## Instalación y ejecución

1. Clonar el repositorio: `git clone https://github.com/<usuario>/sigr.git`
2. Abrir la carpeta `sigr` en Visual Studio Code.
3. Verificar que los archivos estén ubicados correctamente (ver estructura).
4. Abrir el archivo `index.html` en el navegador o con Live Server.

## Control de versiones

- Herramienta: Git.
- Rama principal estable: `main`.
- La línea base del proyecto corresponde a la versión inicial estable del
  código fuente, cuyos detalles se documentan en el taller AA2.
