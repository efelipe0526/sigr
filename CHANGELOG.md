# Historial de cambios — SIGR

## [1.0.0] — 2026-11-08 — Línea base inicial completa

### Agregado

- Migración del prototipo a React, TypeScript y Vite.
- Autenticación demostrativa para los roles cliente, mesero y administrador.
- Menú digital con imágenes locales de hamburguesa, perro caliente y papas fritas.
- Operaciones CRUD de platos y categorías.
- Carrito con cantidades, cálculo automático del total y confirmación de pedidos.
- Seguimiento de pedidos con cuatro estados y actualización por personal autorizado.
- Registro y confirmación de reservas por fecha y hora.
- Reporte diario de ventas, ticket promedio, exportación CSV e impresión.
- Registro de cierres de caja con responsable, fecha, número de pedidos y total.
- Persistencia local de los elementos de configuración y datos operativos.
- Pruebas unitarias y pruebas básicas de integración con Vitest y Testing Library.
- Documentación del modelo de datos, manual de despliegue y validación.
- Diseño adaptable para computador, tableta y teléfono.

### Documentado

- Instalación y ejecución mediante `npm install` y `npm run dev`.
- Compilación de producción mediante `npm run build`.
- Ejecución de pruebas mediante `npm test`.
- Estructura del proyecto y cuentas demostrativas.
